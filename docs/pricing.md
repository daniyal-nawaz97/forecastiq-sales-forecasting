# Packages and pricing (suggested; adjust to your market)

| Package | Monthly | Includes |
|---|---|---|
| **Starter** | PKR 20,000 | Company-level forecast, monthly PDF report, one user |
| **Business** | PKR 50,000 | Product & branch forecasts, scenarios, accuracy screen, stock alerts, team access |
| **Enterprise** | Custom | Live data connections, inventory planning, custom models, private hosting, priority support |

- **Project fee** for the first setup and forecast: PKR 50,000-150,000 (data cleanup, events calendar, accuracy review, training).
- **Monthly retainer**: refreshed forecast each month + a 30-minute review call.
- Position it as **decision support for stock and cash-flow planning**, not a crystal ball.
- No API costs: all calculations run on your server.

Landing-page prices live in `static/landing.html`.
